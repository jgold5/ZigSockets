Zig WebSockets (Old Project)

A small Zig project where I built an HTTP upgrade handshake + a basic WebSocket server/client to learn low-level networking.

Goals

  • Learn socket IO + event loops
  • Implement HTTP Upgrade: websocket
  • Handle multiple clients (epoll)
  • Keep code simple + inspectable

What I built

  • Server
    • TCP listener
    • HTTP request parse (enough for headers)
    • WebSocket upgrade response (101 Switching Protocols)
    • Frame read/write (text frames)
  • Client
    • Connect + send upgrade request
    • Read upgrade response
    • Send a text frame, read echo

Architecture

  • server.zig: listener + accept loop, per-conn state machine
  • main.zig: wiring / runnable entrypoints for tests
  • ws/: handshake + frame codec helpers

Handshake notes

  • Parse headers, especially:
    • Sec-WebSocket-Key
    • Sec-WebSocket-Version
  • Compute:
    • Sec-WebSocket-Accept = base64(sha1(key ++ magic_guid))
  • Reply with 101 + required headers.

Frame codec notes

  • Parse header bits:
    • FIN, opcode
    • MASK, payload_len (7/16/64)
  • Client->server frames are masked (xor with mask key).
  • Implement minimal opcodes:
    • 0x1 text
    • 0x8 close
    • 0x9 ping / 0xA pong (optional)

Epoll / concurrency

  • Single-threaded event loop with epoll
  • Per-connection buffers:
    • read buffer
    • write buffer / pending sends
  • Treat parsing as incremental (don’t assume full frame arrives at once)

Testing checklist

  • Browser connects + sends a message
  • Multiple clients can connect
  • Ping/pong doesn’t kill connection
  • Close frame shuts down cleanly
  • Partial reads: headers split across recv calls
  • Large payloads (len 126/127 paths)
